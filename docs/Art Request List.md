# Koi Pond: art request list

Every icon, emoji and code-drawn picture in the koi pond game, listed by what it should become. These pictures already exist and don't need replacing: Kiko, the plants, the critters, the three filter cutaways, the meadow, the pebbles and the beaver.

**Style for every piece:** the same soft watercolor as your current plant and koi paintings. Transparent PNG, roughly 1024px.
- **Cut-out:** an object on its own, with a transparent background.
- **Scene:** a 4:3 picture that fills its frame.

## Priority if you're making these in batches
1. B (machines). These show up the most and are still emoji.
2. D (problem/fix pairs). This is where kids learn the most.
3. H 86–90 (helper, ammonia, poop, plant food, bubble). Once these characters exist, all the story pictures can use them.
4. A 1–4 (backgrounds).
5. Everything else.
